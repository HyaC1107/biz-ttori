### fanbird 송출 앱 아키텍처
- **스트리밍**: RTMP(IVS Low-Latency HLS) 유지, WebRTC(Stage)는 VIP 실시간 경매 기능 도입 시로 보류.
- **RN 방식**: React Native CLI(bare) — Expo의 SPM 지원 자체는 real이지만, 커스텀 basic broadcast SDK 브릿지 작업엔 선례가 없어 이점이 상쇄됨. 참고: [[projects/close/Docs/송출앱_기술설계서]]
- **스코프**: 방송 예약은 취소만(신규 생성 폼은 웹 전용), 뱃지/색감 변경은 신규 기능이라 Phase 2로 분리.
- **⚠️ 리스크**: 백그라운드 유지 정책이 "유지"로 확정됐으나, **iOS는 OS 레벨에서 백그라운드 카메라 캡처 자체가 불가** — 1차는 화면 자동잠금 방지까지가 현실적 목표. Android는 Foreground Service로 완전 유지 가능.
