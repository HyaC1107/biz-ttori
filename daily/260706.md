**계약 버그 수정 (웹 close 코드 대조로 확정)**
- **로그인**: 요청 파라미터 `id/password` → `userid/userpw`. 실 dev API로 실증(400 "property id should not exist" → 201 토큰발급, JWT `user_level: master`).
- **라이브 목록**: 응답이 배열이 아니라 `{ liveList, total }` wrapper. `res.data.liveList` + `currentPage/perPage/sort` 파라미터로 수정. `live_limit`은 라이브 시간(분)이 아니라 **인원 제한(명)**으로 정정.

- 네이티브(iOS/Android)에 장치 `position`(front/back) 노출 추가 → 기본 카메라를 전면(셀피)으로 선택.
- **Android 검은화면 근본 원인 수정**: RN이 커스텀 네이티브 뷰(FrameLayout)의 자식을 measure/layout 하지 않아 IVS 프리뷰가 0 크기로 렌더됨. `requestLayout` 오버라이드로 자식 강제 재배치. (카메라는 정상 동작 — logcat 프레임 확인으로 레이아웃 문제로 좁힘) → stack.md #4
- COVER 목업 오버레이 제거 → 실카메라 프리뷰만 마운트.

**로그인 키보드 가림 (edge-to-edge)**
- Android 16 / targetSdk 36 edge-to-edge 강제로 `adjustResize` 무시 → KAV/ScrollView 무력화. `Keyboard` 이벤트로 높이 받아 `paddingBottom`으로 밀어올려 해결. → stack.md #5
