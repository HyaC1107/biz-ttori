# **🗺️ 팬버드 라이브커머스 Phase별 직군 작업 명세서 v1 260630**

## **🚀 \[1차 (Phase 1)\] 핵심 커머스 및 송출 (Must-be)**

### **🎨 1\. UI/UX 디자이너**

* **\[방송/송출 UI\]** RN 기반 모바일 송출/시청 화면 설계 (실시간 채팅창, 접속자 수 뱃지, 상품 팝업 오버레이 UI).  
* **\[상품/주문 관리 UI\]** 어드민 내 상품 등록/수정 폼 및 노출 순서 변경(Drag & Drop 등) UI, 주문 상태(결제대기/완료/취소) 변경 관리자 페이지 설계.  
* **\[운영 대시보드 UI\]** 스토어 ON/OFF 토글, 시청자/매출/주문/채팅 통합 라이브 통계 대시보드 화면 설계.  
* **\[결제/설정 UI\]** PG사(카드/내통장결제) 및 무통장 입금 결제 화면 디자인, 배송비/수수료 등 스토어 기본 설정 페이지 설계.

### **💻 2\. 프론트엔드 (React / React Native)**

* **\[RN SDK 연동\]** Low Latency 라이브 스트리밍 플레이어 및 카메라/오디오 포커싱 제어 모듈 연동.  
* **\[영상-데이터 싱크\]** 라이브 영상 프레임(이벤트)에 맞춰 '상품 팝업'이 지연 없이 노출되도록 싱크 최적화 처리.  
* **\[실시간 소통\]** WebSocket(또는 WebRTC) 기반 실시간 채팅 및 접속자 수 카운팅 렌더링.  
* **\[어드민 기능 제어\]** 방송 중 상품 실시간 가격/재고 수정 및 노출 순서 변경 API 연동, 스토어 ON/OFF 스위칭 처리.

### **⚙️ 3\. 백엔드 및 인프라 (Node.js / Java 등)**

* **\[스트리밍 인프라\]** 3\~4천 명 동시 접속을 버틸 수 있는 라이브 스트리밍 서버(AWS IVS 등) 아키텍처 구축.  
* **\[DB & API 설계\]** 실시간 상품 재고 차감 로직, 주문 상태 변경 API, 방송 예약 및 알림 발송 스케줄러(알림톡 API 연동) 구축.  
* **\[결제/PG 연동\]** PG사 웹훅(Webhook) 수신 및 무통장 입금(가상계좌 등) 결제 상태 동기화 처리 (Phase 1은 어드민 결제 취소만).  
* **\[마케팅 데이터 연동\]** 어웨이크(광고 대행사)로 넘겨줄 가입자/구매자 데이터 API 및 2차 도메인(CNAME) 인프라 환경 세팅.

## **⚡ \[2차 (Phase 2)\] 운영 자동화 및 성과 고도화 (Performance)**

### **🎨 1\. UI/UX 디자이너**

* **\[결제 UX 개편\]** 용어 변경('득템 리스트', '구매 예약') 적용 및 방송 종료 후 '원클릭 일괄 결제' 프로세스 UI 설계.  
* **\[가입/비회원 UX\]** 카카오싱크 1 Click 가입 모달 설계 및 비회원의 오픈 시청 화면 제어 UX.  
* **\[물류 자동화 UI\]** 상품별 다중 송장 번호 입력 필드, 무통장 입금 엑셀 업로드(매칭) UI, **N차 발주 상태 기반 엑셀 다운로드 팝업 설계.**  
* **\[CS 관리 UI\]** 공지/매크로 메시지 관리 폼, 악성 유저 차단 스케줄러 세팅 모달, 오타 대응(Fuzzy) 검색창 적용.

### **💻 2\. 프론트엔드 (React / React Native)**

* **\[카카오싱크 라우팅\]** 인앱 브라우저를 이탈하지 않도록 카카오싱크 로그인 리다이렉트(location.href) 로직 최적화.  
* **\[결제/장바구니 고도화\]** 방송 중 실시간 상품 카드 결제(혼합 결제) 허용 및 득템 리스트 일괄 결제 장바구니 로직 개발.  
* **\[채팅 고도화\]** 채팅창 내 공지 메시지 상단 고정, 채팅 음소거(본인 화면 노출 유지), 관리자 매크로 메시지 전송 기능 개발.  
* **\[배송 데이터 렌더링\]** 백엔드에서 배열(Array) 형태로 내려오는 '배송현황 2개 이상 다중 송장표'를 화면에 파싱하여 노출.

### **⚙️ 3\. 백엔드 및 인프라 (Node.js / Java 등)**

* **\[발주/물류 트랜잭션\]** (⭐️ 이지텍 대응 핵심) 엑셀 다운로드 시점 주문건 Lock(스냅샷) 및 상태 자동 변경, N차 발주 태깅 처리.  
* **\[대용량 배치(Batch) 처리\]** 100건 이상 대량 발주/송장 엑셀 업로드 시 서버 다운을 막는 비동기(Background) 리포트 처리 및 미입금자 재알림톡 자동 발송.  
* **\[검색 및 CS 필터\]** 상품/주문 상세 상태 다중 필터링 쿼리 최적화, 오타 대응 유연한 검색(Fuzzy Search / ElasticSearch 등 적용 검토).  
* **\[스케줄러 고도화\]** 악성 유저 차단 및 해제 예정일에 맞춘 자동 크론(Cron) 스케줄러 개발.

## **💎 \[3차 (Phase 3)\] 마케팅 확장 및 게임화 (Attractive)**

### **🎨 1\. UI/UX 디자이너**

* **\[게임화 UI/VFX\]** 공동 목표 달성 '게이지' 애니메이션, 완판 시각적 효과(VFX), 숨겨진 할인 '황금 티켓', '지각쟁이 뱃지' 아이콘 디자인.  
* **\[멤버십/커뮤니티 UI\]** VIP/GOLD 등급 뱃지 및 표시 영역, 4050 타겟 맞춤형 '출석/럭키박스' UI, 커뮤니티(게시판) 설계.  
* **\[마케팅 통계 UI\]** 추천인 기반 매출 및 구매액/횟수 기반 고객 등급/전환율 관리 대시보드 차트 설계.

### **💻 2\. 프론트엔드 (React / React Native)**

* **\[인터랙션/VFX 구현\]** Lottie 또는 CSS Animation을 활용한 방송 화면 내 '가자\! 게이지', 완판 효과, 티켓 팝업 등 부하 없는 애니메이션 처리.  
* **\[맞춤형 알림/UI 제어\]** 특정 초대 링크로 입장 시 채팅창 상단에 맞춤형 환영 알림 노출, 등급별 뱃지 프론트 렌더링.  
* **\[취소 티켓 로직\]** 방송 중 유저별 제한적 취소(티켓 차감) 로직 프론트 방어선 구축.

### **⚙️ 3\. 백엔드 및 인프라 (Node.js / Java 등)**

* **\[확장성 아키텍처(마켓플레이스)\]** 향후 외부 셀러 입점이 가능하도록 단일 입점사(Single-tenant) DB 구조에서 다중 입점사(Multi-tenant) 마켓구조로 스키마 리팩토링.  
* **\[마케팅 엔진\]** 특정 유저 상품 일괄 추가, 추천인 트래킹 및 매출 집계, 구매 데이터 기반 유저 등급 자동 갱신 엔진.  
* **\[AI/자동화 연동\]** 외부 AI STT(음성 인식) API를 연동하여 방송 스크립트 자동 추출 및 즉시 다시보기(VOD) 인코딩 인프라 구축.
