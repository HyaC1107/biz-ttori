# 📋 모바일 송출앱 실기기(iOS & Android) 테스트 체크리스트

모바일 송출앱(fanbird-broadcast)의 원활한 QA 및 마켓 검증을 위해, 안드로이드와 iOS 기기에서 테스트할 때 중점적으로 확인해야 할 기기별 상세 체크리스트입니다.

---

## 1. 🍎 iOS 실기기 전용 체크리스트 (iPhone 13 등)

| ID | 테스트 항목 | 검증 방법 및 기대 결과 | 결과 (P/F) |
|---|---|---|---|
| **i-1** | **카메라/마이크 권한 요청** | 앱 최초 진입 시 iOS 시스템의 카메라, 마이크 권한 요청 팝업이 한 번씩 정상 노출되는가? 허용 시 송출 프리뷰가 정상 활성화되는가? | |
| **i-2** | **백그라운드 진입 및 복귀** | 홈 화면으로 나가거나 화면을 잠갔을(Lock) 때 송출 세션의 상태 가드(웹뷰 및 네이티브 세션 유지)가 정상 작동하는가? 앱으로 복귀 시 카메라 프리뷰 화면이 굳지 않고 부드럽게 재개(Resume)되는가? | |
| **i-3** | **화면 자동 꺼짐 방지** | 라이브 송출 도중 기기를 조작하지 않아도 iOS 화면 자동 꺼짐(Sleep)이 방지되는가? (`isIdleTimerDisabled = true` 연동 검증) | |
| **i-4** | **노치 및 SafeArea 레이아웃** | iPhone 13 등의 상단 노치 및 하단 홈 바 영역과 방송 화면 UI(시청 인원수, 방송 시작 버튼, 채팅 입력창 등)가 겹쳐서 터치가 불가능하지 않은가? | |
| **i-5** | **오디오 세션 라우팅** | 방송 도중 에어팟(AirPods) 등 블루투스 이어폰을 연결하거나 해제할 때, 마이크 입력이 블루투스 마이크 ↔ 아이폰 내장 마이크로 매끄럽게 전환되는가? | |

## 🤖 2. Android 실기기 전용 체크리스트 (갤럭시 등)

| ID | 테스트 항목 | 검증 방법 및 기대 결과 | 결과 (P/F) |
|---|---|---|---|
| **a-1** | **하드웨어 백버튼 이탈 방지** | 방송 송출 도중 Android 하드웨어 뒤로가기(Back) 키 또는 내비게이션 제스처 시 즉각 화면을 이탈하지 않고, "방송을 종료하시겠습니까?" 경고 얼럿이 정상 작동하는가? | |
| **a-2** | **포그라운드 서비스 및 노티** | 송출 중 백그라운드로 앱이 내려갈 때, 안드로이드 상단바 노티피케이션 영역에 방송 송출 중임을 알리는 포그라운드 서비스 알림이 안전하게 실행되는가? | |
| **a-3** | **권한 거부 대응 플로우** | 최초 권한 요청 시 사용자가 카메라/마이크 권한을 거절했을 때, "권한 설정이 필요합니다" 안내와 함께 스마트폰 앱 설정 화면으로 이동시키는 팝업 안내가 작동하는가? | |
| **a-4** | **다크 모드 시스템 테마 대응** | 안드로이드 시스템 테마를 '다크 모드'로 변경했을 때, 텍스트 색상이나 입력창이 검은색 배경에 묻혀서 안 보이지 않는가? (테마 스타일 깨짐 방지) | |
| **a-5** | **다양한 기기 사양 파편화 대응** | 보급형 갤럭시 A 시리즈 및 구형 OS 버전 기기에서 방송 프리뷰 렌더링 시 레이턴시가 심하게 밀리거나 크래시가 나지 않는가? | |

## 🌐 3. 공통 E2E 및 네트워크 예외 체크리스트

| ID | 테스트 항목 | 검증 방법 및 기대 결과 | 결과 (P/F) |
|---|---|---|---|
| **c-1** | **장기 송출 발열 및 배터리** | 라이브 인코딩 및 송출을 최소 20분 이상 지속했을 때 기기 과열로 인한 쓰로틀링(프레임 드랍)이나 배터리가 비정상적으로 급감하며 앱이 튕기지 않는가? | |
| **c-2** | **전화 수신/푸시 알림 대응** | 방송 도중 실기기로 일반 전화가 수신되었을 때, 송출 세션이 유지 및 일시정지 상태로 버티고 통화 종료 후 앱 복귀 시 자동 재연결(Auto Reconnect)되는가? | |
| **c-3** | **네트워크 순단(비행기 모드) 대응** | 송출 도중 Wi-Fi나 데이터 연결이 끊겼을 때, "네트워크 재연결 중입니다" 인디케이터가 뜨고, 망이 복구되면 방송이 끊기지 않고 재송출이 매끄럽게 재개되는가? | |
| **c-4** | **싱크 (A/V Sync) 일치** | 시청자 화면(웹뷰)에서 확인했을 때, 판매자의 입 모양(비디오)과 목소리(오디오) 간의 타임 갭이 0.5초 이내로 싱크가 정상 유지되는가? | |
| **c-5** | **소켓 기반 실시간 이벤트 동기화** | 시청자가 웹에서 채팅을 칠 때 송출앱 화면에 실시간으로 반영되는지, 시청자 증감에 따라 송출앱 시청 인원 카운트 수치가 즉각 변동하는지 여부. | |
