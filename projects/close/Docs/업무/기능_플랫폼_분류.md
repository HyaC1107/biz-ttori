전체 기능 백로그를 **어느 플랫폼/대상**의 작업인지로만 분류(견적/우선순위 아님).
- **RN 송출앱** = `/Users/linkcampus02/fanbird-broadcast` (판매자 송출)
- **웹-시청자** = `close` `src/Page/User/*` (구매자/User)
- **웹-관리자** = `close` `src/Page/Manage/*` (Admin)
- 걸침 = 여러 플랫폼에 나뉨

## 📱 RN 송출앱 (판매자)
- 카메라·오디오 기본 포커싱 자동화
- Android/iOS 모두 송출 (현재 iOS만 허용 상태)
- 방송 예약 **취소** (생성·알림은 웹-관리자)
- 라이브 홈에서 바로 송출(비회원) — *송출 주체가 앱이면 여기, 웹 송출이면 관리자*

## 🖥️ 웹 – 시청자 (구매자/User)
- 플레이어 싱크 + **상품 팝업 노출** (항목엔 "RN SDK"라 표기됐으나 실제 시청 화면은 웹 플레이어)
- PG·무통장 결제 / **원클릭 일괄 결제**
- 득템 리스트(담기=구매예약) 용어 적용
- 카카오싱크 로그인(마케팅 동의)
- 방송 중 실시간 상품 이미지 노출 — *트리거는 관리자·송출*
- 문의하기
- 서비스 이용·개인정보 처리방침
- 취소 티켓(방송 중 제한적 취소) 프론트 방어선
- 쓰리백 패스 구독 / 출석·럭키박스 보상 / 황금 티켓 수령
- VFX: 가자! 게이지, 완판/오픈 시각효과
- 커뮤니티 게시글·댓글 작성
- AI 즉시 다시보기 — *스크립트 추출은 AI 백엔드*

## 🛠️ 웹 – 관리자 (Manage/Admin)
- 방송 예약 **생성** + 알림 발송
- 상품 등록/수정/삭제 (방송중 캡처는 RN, 보류)
- 가격·재고 실시간 수정
- 주문 상태 관리자 수정
- 방송별 주문내역 / 통합 라이브 운영 대시보드
- 스토어 ON/OFF
- 재설정(합배송·택배비·수수료·알림톡·AWS)
- 무통장 자동·수동 매칭(엑셀 추출)
- 상품별 개별 송장 등록 → **다중 송장 표출**(배열 파싱)
- 고객별 주문 묶음 / 특정 유저 상품 일괄 추가
- 100건+ 대량 배치 + 백그라운드 리포트
- 미입금 재알림톡(실패 사유 노출)
- 엑셀 발주 스냅샷(N차 발주 상태관리)
- Fuzzy Search + 재고 필터 / 다중 필터·일괄변경·퀵메뉴 복사
- 악성 유저 차단 스케줄러(해제 예정일 자동)
- CS 담당자 지정·이력·대시보드
- 방송 예고·소식 게시글 작성
- 추천인 트래킹·매출 집계
- 고객 등급 관리 + 전환율 분석

## 🔀 걸침 (여러 플랫폼)
- **공지 상단 고정 + 매크로**: RN송출앱(호스트 등록) + 웹-시청자(표시) *(+관리자 채팅관리 시)*
- **채팅 음소거(본인 노출 유지)**: 웹-시청자 + RN송출앱(호스트)
- **닉네임 등급 뱃지 / 지각쟁이 뱃지**: 표시=웹-시청자+RN 채팅 · 설정=웹-관리자
- **초대링크 입장 환영 알림**: 웹-시청자(입장) + 채팅 상단
- **혼합 결제**: 설정=웹-관리자 · 결제=웹-시청자
- **유저 등급 실시간 갱신**: 백엔드 + 표시(시청자 채팅)/관리(관리자)
- **플레이어 오디오/영상 싱크**: 송출 품질=RN · 팝업 싱크=웹-시청자
