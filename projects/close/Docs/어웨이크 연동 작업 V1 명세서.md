## **1\. 개요 (Overview)**

* **목표:** 외부 마케팅 트래픽의 유실(이탈률)을 최소화하고, 카카오 인앱 브라우저 환경에서 매끄러운 회원가입 및 결제 전환(ROAS)을 달성하기 위한 인프라 및 API 연동.  
* **적용 대상:** 기획/UX팀, 프론트엔드(React/RN)팀, 백엔드/인프라팀

## **2\. 인프라 및 도메인 세팅 (Infra & Domain)**

### **\[Task 2.1\] 2차 도메인 CNAME 설정**

* **내용:** 어웨이크 랜딩페이지 접속을 위한 도메인 레코드 추가  
* **조치:** 도메인 관리자(가비아 등)에서 아래 레코드 추가  
  * Type: CNAME  
  * Name: live (결과: live.오늘만.com)  
  * Target: 어웨이크 측이 제공하는 랜딩페이지 서버 주소

### **\[Task 2.2\] Root Domain 쿠키 굽기 (⭐️ 백엔드 핵심)**

* **내용:** 2차 도메인과 본 도메인 간의 세션 공유를 위한 마스터키 설정  
* **조치:** 로그인 성공 시 발급하는 JWT Refresh Token의 쿠키(Cookie) 옵션을 아래와 같이 설정.  
  * Domain: .오늘만.com (앞에 점이 반드시 들어가야 함)  
  * HttpOnly: true  
  * Secure: true (HTTPS 필수)

## **3\. 프론트엔드 (UI/UX 및 라우팅)**

### **\[Task 3.1\] 기존 회원 하이패스 API 호출 (어웨이크 랜딩)**

* **내용:** 랜딩페이지 진입 시 로그인 여부 체크  
* **조치:** 랜딩페이지 로드 직후 팬버드 백엔드의 GET /api/v1/auth/session-check API 호출.  
  * 브라우저가 알아서 Root 도메인 쿠키를 담아 보냄.  
  * 응답이 isLoggedIn: true 일 경우 랜딩페이지를 노출하지 않고 즉시 메인 쇼핑몰(www.오늘만.com)로 리다이렉트(location.href).

### **\[Task 3.2\] 1 Click 카카오싱크 직행 (중간 팝업 제거)**

* **내용:** '단골맺기' 버튼 클릭 시 불필요한 팝업 없이 즉시 노란색 카카오 인가 화면으로 이동.  
* **조치:** 버튼 클릭 시 바로 카카오 OAuth API (https://kauth.kakao.com/oauth/authorize?...)로 라우팅 처리.

### **\[Task 3.3\] 비회원 오픈 시청 및 Gated 모달**

* **내용:** 시청 자체는 로그인 없이 100% 개방.  
* **조치:**  
  * 로그인 상태가 아닐 때 '채팅 입력창' 또는 '장바구니/구매하기' 버튼 클릭 시 화면 중앙에 고정(Fixed)되는 \[1초 단골맺기\] 카카오싱크 유도 모달 띄우기.

### **\[Task 3.4\] 카카오 인앱 브라우저 세션 유지**

* **내용:** 랜딩페이지 \-\> 메인 쇼핑몰 이동 시 외부 브라우저(Safari 등)로 이탈 방지.  
* **조치:** window.open(url, '\_blank') 등의 새 창 열기 방식 사용 금지. 반드시 현재 창에서 이동하는 location.href \= 'www.오늘만.com' 방식으로 처리하여 인앱 환경 유지.

## **4\. 백엔드 (카카오 인증 및 API 통신)**

### **\[Task 4.1\] 카카오싱크 동의 항목 최소화**

* **내용:** 가입 이탈 방지를 위한 최소 정보만 수집.  
* **조치:** 카카오 디벨로퍼스 앱 설정에서 다음 4가지만 필수로 설정.  
  1. (필수) 카카오계정 이메일  
  2. (필수) 휴대전화 번호  
  3. (필수) 이름  
  4. (필수) 서비스 약관 및 개인정보처리방침  
  * *나머지 정보(배송지 주소 등)는 결제 시점에 팬버드 앱 내에서 추가 수집.*

### **\[Task 4.2\] 토큰 자동 갱신 (Rolling) 로직**

* **내용:** 로그인 풀림 현상 최소화.  
* **조치:** 프론트엔드가 Access Token 만료로 /refresh API를 찌를 때, 카카오 서버에서 새로운 Refresh Token을 내려준다면 반드시 팬버드 DB의 값도 최신화(Update) 처리할 것.

### **\[Task 4.3\] 카카오 Unlink (회원 탈퇴용 어드민 키 적용)**

* **내용:** 회원 탈퇴 시 카카오 리프레시 토큰에 의존하지 않고 확실한 연결 해제 처리.  
* **조치:** 팬버드 서비스 탈퇴 API 호출 시, 서버 내부에서 Admin Key와 Kakao ID(회원번호)를 조합하여 카카오 서버로 Unlink API(POST /v1/user/unlink) 강제 호출.

## **5\. 데이터 통계 연동 (Analytics)**

### **\[Task 5.1\] 마케팅 성과 추적 (ROAS) API 제공**

* **내용:** 어웨이크 측이 광고 효율을 분석할 수 있도록 통계 데이터 제공.  
* **조치:** 어웨이크 서버만 접근 가능한 전용 API(또는 API Key) 생성.  
  * **Endpoint:** GET /api/v1/stats/marketing  
  * **Params:** startDate, endDate, interval(daily/hourly)  
  * **Response Data:**  
    * new\_signup\_count: 신규 카카오싱크 가입자 수  
    * additional\_info\_count: 추가 정보(주소 등) 입력 완료자 수  
    * new\_buyer\_count: 첫 구매 완료자 수  
  * *(백업 플랜: API 개발이 지연될 경우, 팬버드 어드민 페이지 내 '마케팅 통계 엑셀 다운로드' 버튼으로 임시 대체 가능)*

# **📋 어웨이크(Awake) 최종 요구사항 직군별 작업 명세서**

**문서 목적:** 마케팅 대행사(어웨이크)가 요청한 '고객 유입 최적화 및 전환율 극대화' 관련 9가지 요구사항을 실무 직군별 Task로 분류하여 즉시 개발/디자인 스프린트에 반영하기 위함입니다.

## **🎨 1\. UI/UX 디자이너 (기획/디자인 파트)**

**목표:** 고객이 귀찮아할 만한 불필요한 화면(팝업)을 제거하고, 행동을 유도하는 강력한 모달을 설계합니다.

* **중간 로그인 팝업 제거 (1-Click 진입):**  
  * 랜딩페이지나 홈에서 '단골맺기' 버튼 클릭 시 나타나던 **자체 안내 팝업(팬버드 자체 화면)을 디자인에서 완전히 삭제**합니다. (바로 노란색 카카오싱크 화면으로 넘어가도록 동선 수정)  
* **비회원 시청용 화면 설계:**  
  * 로그인하지 않은 상태(비회원)에서도 라이브 방송과 상품 목록을 구경할 수 있는 '오픈 시청 화면'을 구성합니다.  
  * 채팅 입력창에 '로그인 후 채팅에 참여할 수 있습니다' 등의 플레이스홀더(안내 문구)를 적용합니다.  
* '1초 단골맺기' 모달 디자인:  
  * 비회원이 채팅창을 누르거나 구매(장바구니) 버튼을 누를 때 화면 중앙에 뜨는 가입 유도 모달을 디자인합니다.  
  * **핵심 조건:** 스크롤을 내리거나 배경을 터치해도 쉽게 사라지지 않도록 중앙에 고정(Fixed)되는 형태로 디자인해야 합니다.  
* 바텀업(Bottom-up) 모달 디자인:  
  * 카카오싱크로 간편 가입은 했으나 배송지(주소)나 닉네임 정보가 없는 '단순 가입 회원'이 구매 후 화면 아래에서 위로 올라오는 '추가 정보 입력' 모달을 디자인합니다.  
* 라이브 통계: 어웨이크 제공 데이터 표출  
  * **방송별 ① 일/시간별 신규 가입자 수 ② 추가 정보 입력 완료자 수 ③ 신규 구매 회원 수**

## **💻 2\. 프론트엔드 (React / React Native 파트)**

**목표:** 인앱 브라우저를 꽉 잡아서 이탈을 막고, 매끄러운 화면 전환과 가입(Gate) 로직을 구현합니다.

* **기존 회원 하이패스 (Session Check):**  
  * 랜딩페이지(live.오늘만.com) 접속 시점(Mount)에 백엔드 API를 찔러 로그인 상태인지 확인합니다.  
  * 이미 로그인된 유저라면 0.1초 만에 메인 홈(www.오늘만.com)으로 강제 이동(Redirect)시킵니다.  
* **카카오 인앱(In-App) 브라우저 유지 (가장 중요):**  
  * 카카오톡에서 링크를 눌러 들어온 유저가 랜딩페이지 ➔ 메인 홈으로 이동할 때, 사파리나 크롬 등 외부 브라우저로 튕겨 나가지 않도록 **location.href 방식 등을 사용해 현재 창 이동으로 라우팅**을 처리합니다. (새 창 열기 금지)  
* **비회원 기능 개방 및 Gated Action 제어:**  
  * 비회원에게 방송 영상 및 상품 목록 접근 권한을 오픈합니다.  
  * 단, 비회원의 onClick(채팅하기), onClick(구매하기) 이벤트 발생 시 정상 로직을 막고(e.preventDefault), 디자이너가 만든 **'1초 단골맺기 모달'을 호출**하도록 분기 처리합니다.  
* **1-Click 카카오싱크 다이렉트 라우팅:**  
  * '단골맺기' 모달 또는 버튼의 onClick 액션 시, 팬버드 자체 라우팅을 거치지 않고 곧바로 카카오 OAuth 인가 URL(https://kauth.kakao.com/...)로 점프시킵니다.

## **⚙️ 3\. 백엔드 및 인프라 (Node.js / Java 등)**

**목표:** 끊김 없는 쿠키 공유 인프라를 만들고, 최소한의 정보만으로 가입을 처리하며, 마케팅 성과 데이터를 제공합니다.

* **2차 도메인 인프라 세팅 (DNS CNAME):**  
  * 셀러의 메인 도메인(예: 오늘만.com) 관리자 페이지에서 live라는 이름으로 CNAME 레코드를 추가하고, 타겟을 어웨이크 랜딩페이지 서버 IP/도메인으로 연결합니다.  
* **세션 공유용 마스터 쿠키 굽기:**  
  * JWT 토큰 등을 쿠키로 프론트에 내려줄 때, 쿠키의 Domain 옵션을 반드시 Root 도메인(예: .오늘만.com \- 앞에 점 포함)으로 설정하여 2차 도메인과 본 도메인 간 로그인 정보가 자동으로 공유되도록 세팅합니다.  
* **카카오싱크 필수 동의 항목 최소화 설정:**  
  * 카카오 디벨로퍼스 관리자 콘솔에서 필수 동의 항목을   
    $$이메일, 전화번호, 이름$$  
    3가지로만 축소 설정하고, 채널 추가를 선택으로 넣습니다.  
* **로그인 유지 세션 타임(TTL) 최대화:**  
  * 어웨이크의 "로그인이 잘 풀린다"는 클레임 방지를 위해, 자체 발급하는 Refresh Token의 만료 기간(만료 시 자동 연장 로직 포함)을 시스템이 허용하는 최대치(예: 6개월\~1년)로 길게 세팅합니다.  
* **어웨이크 마케팅 성과 추적 데이터 제공 (API 또는 어드민):**  
  * 광고 효율 분석을 위해 어웨이크 측이 요구하는 3가지 데이터 **① 일/시간별 신규 가입자 수 ② 추가 정보 입력 완료자 수 ③ 신규 구매 회원 수**를 어웨이크 서버로 전송하는 API를 개발하거나, 셀러 어드민에서 엑셀로 일괄 다운로드할 수 있는 메뉴를 구축합니다.
