### 구현 기능
- 표 헤더 **필터 아이콘**(`icon_more_active`/`deactive`): 자재명·규격·상태·위치·담당자. 클릭 시 모달.
  - 자재명/규격은 **같은 모달**("자재 및 규격 선택")을 염.
- **모달 4종**(모두 다중선택, 전체선택 체크박스, `선택완료`):
  - 자재 및 규격 / 상태 / 보관위치 / 담당자
- **선택 필터 칩**: 회색 글씨·배경 없음, 개별 `✕` 제거, 줄 넘치면 다음 줄로(wrap).
- **초기화 버튼**(`icon_refresh`): 컬럼 필터 + 검색어 + 기간 전부 리셋.
- **기간 필터**(상단): 시작일 ~ 종료일 (`icon_download` 엑셀버튼 좌측, 초기화 우측).
- **통합 검색바**(하단): 카테고리 드롭다운(자재명/보관위치/담당자/상세내용) + 입력창 + 검색 아이콘 한 박스.
- **페이지당 개수**(우측 하단): 10/20/30/40/50개씩 보기 (기본 10).
- **엑셀 다운로드**: 버튼만 존재(클릭 시 "준비 중" alert). ⚠️ 미구현.

### 옵션(모달 목록) 출처
- 자재+규격: `materialAPI.load()`(전체), 위치: `storageAPI.load()`, 상태: 고정값(입고/출고/이동/등록/수정/삭제)
- **담당자: 임시방편** — 현재 불러온 목록의 담당자 고유값을 누적. **백엔드 distinct 엔드포인트로 교체 필요.**

### ⭐ 백엔드 연동 계약 (`history_list` 가 받아야 할 파라미터)
프론트는 이미 아래를 전송 중. 백엔드가 받아 **서버에서 필터링 + 재페이징**하면 즉시 동작.

| 항목 | 파라미터 | 형식/예시 |
|------|----------|-----------|
| 자재+규격 | `mat_seq` | 콤마 다중 `9,10` |
| 상태 | `his_type` | 콤마 다중 `입고,출고` |
| 위치 | `sto_seq` | 콤마 다중 `1,2` |
| 담당자 | `worker` | 콤마 다중 `강홍길,나홍길` |
| 기간 시작 | `start_dt` | `2026-06-01` |
| 기간 종료 | `end_dt` | `2026-06-30` |
| 검색 키 | `search_key` | `mat_name`/`sto_name`/`worker`/`his_note` |
| 검색어 | `search_value` | 텍스트 |
| 페이지당 | `per_page` | 10~50 |

> 파라미터명/구분자가 백엔드와 다르면 `useHistoryList.tsx`의 `join`/키 이름만 바꾸면 됨.

## 4. 테스트 서버 운영 메모 (인프라)

- 증상: 프론트 "Network Error" = 보통 테스트 백엔드 다운(502)인데 502에 CORS 헤더가 없어 브라우저가 막는 것. **프론트 코드 문제 아님.**
- 서버: EC2 `52.78.248.251` (ec2-user). nginx `/yongsangu_T/back/` → `127.0.0.1:3010`.
- 백엔드: NestJS, `/var/www/nginx/yongsangu_T/back` (dist 빌드 존재).
  - `.env` = PORT 3000, `.env.test` = PORT 3010 → 3010 띄우려면 `NODE_ENV=test`.
- 기동(root pm2):
  ```bash
  cd /var/www/nginx/yongsangu_T/back
  sudo env NODE_ENV=test pm2 start dist/main.js --name yongsangu_T --update-env
  sudo ss -tlnp | grep 3010   # 확인
  ```
- 진단: `sudo tail /var/log/nginx/error.log` (connect() failed=앱 다운), `sudo ss -tlnp | grep 3010`.
- 주의: `pm2 save`는 dump를 덮어씀. 기존 dump에 별도 프로젝트 `safety-manage`(`/var/www/nginx/safety_management_system`)가 있음 — 그게 떠 있어야 하면 `pm2 resurrect` 후 함께 save.
