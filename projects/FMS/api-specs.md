### 다중선택 필터 구분자 — `@`

다중선택 필터는 여러 값을 **`@`로 이어붙여** 전송한다. 백엔드는 **`@`로 split**해서 파싱한다.

| 파라미터 | 의미 | 값 출처 |
|:---|:---|:---|
| `mat_name` | 자재명들 | 선택 자재의 `mat_name` |
| `mat_size` | 규격들 | 선택 자재의 `mat_size` |
| `sto_name` | 창고 이름들 | 선택 위치의 `storage_sto_name` |
| `his_type` | 상태들 | `입고`/`출고`/`이동` (고정값) |
| `worker` | 담당자들 | 담당자명 문자열 |

예) `mat_name=볼트@너트@와셔`

### ⚠️ 계약 변경 이력
- **2026-07-07**: 구분자 `,` → `@` 변경.
  - **이유**: 자재명/규격에 콤마가 들어가면 기존 `,` 구분자와 충돌해 필터가 깨짐.
  - **동반 조치(FE)**: 자재명·종류·규격(`MaterialInsert`/`MaterialModi`), 창고 이름(`StorageModal`) 입력에서 `@` 입력 차단 → 값 내부에 구분자가 섞이지 않게 함.
  - **🚨 FE/BE 동시 반영 필수** — 한쪽만 바뀌면 필터 전체가 조용히 깨진다.

### 🔴 알려진 리스크 (미해결)
- **`worker`(담당자)는 이름 문자열을 그대로 전송**하는데, 담당자명(=유저명)은 회원관리 영역에서 정해져 자재관리 화면에서 `@` 입력을 막지 못한다.
  → 유저명에 `@`가 포함되면(예: 이메일형 아이디) 담당자 필터가 깨질 수 있음.
  → **완전 해결책**: ① 유저명에 `@` 금지(회원관리), 또는 ② `worker`를 이름 대신 `seq`(숫자)로 전송하도록 계약 변경. (현재 보류 — 문제 발생 시 대응)
