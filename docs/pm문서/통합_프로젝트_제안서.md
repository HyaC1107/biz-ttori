## 🛠️ 1. 추천 기술 스택 및 패키징 아키텍처 제안

국내 개발 인력 시장의 **유지보수 이관(Handover) 용이성**과 **개발 생산성** 사이의 균형을 맞춘 최적의 아키텍처 대안을 제시합니다.

### 1.1 백엔드 아키텍처 비교 제안 (Supabase vs Node.js 표준 스택)
클라이언트가 차후 타 개발사나 프리랜서에게 유지보수를 이관할 때의 리스크를 방어하기 위한 대안 분석입니다.

| 비교 항목 | A안. Supabase (BaaS) | B안. Node.js + MySQL + AWS (추천) |
| :--- | :--- | :--- |
| **백엔드 구성** | Supabase SDK 라이브러리 직접 링킹 | Node.js (NestJS / Express) API 서버 구축 |
| **데이터베이스** | PostgreSQL (Supabase 클라우드) | MySQL 또는 PostgreSQL (AWS RDS) |
| **유지보수 이관성<br>(국내 인력 풀)** | **낮음** (국내 SI/에이전시 중 Supabase RLS 정책이나 트리거를 능숙하게 다루는 개발자 비율이 적음) | **매우 높음** (대한민국 백엔드 개발자 다수가 Node.js와 MySQL, AWS 배포 환경에 익숙함) |
| **개발 공수 (MD)** | **매우 낮음** (인증/채팅/스토리지 연동 70% 세이브) | **보통** (JWT 인증, 소켓 서버, DB ORM 마이그레이션 직접 구현 필요) |
| **종합 제안** | 초기 개발 속도는 압도적이나, **클라이언트의 장기 안정성과 이관을 고려할 때 B안(Node.js 표준 스택)으로 구축하는 것이 무결합니다.** |

*   **B안 적용 시 추천 도구:**
    *   **Prisma ORM:** SQL 쿼리를 직접 짜지 않고 안전하게 관계형 DB를 다룰 수 있어, Supabase 수준의 빠른 개발 속도를 내면서도 순수한 독립 RDB(MySQL)를 사용하므로 장기 이관성이 극대화됩니다.

### 1.2 하이브리드 앱 패키징 솔루션 제안
웹을 만든 뒤 iOS/Android 앱스토어에 앱으로 등록하기 위한 패키징 기술 대조군입니다.

| 비교 항목 | A안. Capacitor (강력 추천) | B안. React Native CLI (비추천) |
| :--- | :--- | :--- |
| **개념** | 작성된 웹(React)을 모바일 Native WebView로 감싸 앱화 | React 코드를 네이티브 UI 컴포넌트로 1:1 변환하여 렌더 |
| **웹 코드 재사용률** | **100%** (모바일용 웹을 그대로 감싸 빌드) | **약 40~50%** (UI 마크업을 아예 새로 코딩해야 함) |
| **네이티브 브릿지** | 간단한 플러그인(카메라, 푸시알림) 설정으로 완결 | iOS Swift / Android Kotlin 브릿지를 직접 설계해야 함 |
| **추천 이유** | - **2인 개발 체제 외주용 최속의 사기 치트키.**<br>- 빌드 오류 및 스토어 심사 리스크를 최소화함. | - 성능은 우수하나, 기한 내 독박 론칭이 사실상 불가능함. |

## 🛍️ 2. 12개 카테고리별 상세 기능 명세 제안

각 카테고리별로 기획 미팅 시 R&R을 나누고 공수를 가늠해 볼 수 있는 필수 기능 추천 리스트입니다.

### 2.1 인터넷TV
*   **Frontend UI:** 3사 통신사별 요금 비교 테이블, 월 결합할인 모의 계산기, 상담 신청 폼.
*   **Backend API/DB:** 신청 데이터 수집 DB, 관리자 알림톡 전송 API.

### 2.2 상가정보
*   **Frontend UI:** 상가 분류별 리스트/검색 필터, 카카오/네이버 지도 지도 마킹 뷰, 상세 정보 및 전화 걸기 버튼.
*   **Backend API/DB:** 상가 위치 위경도(GPS) 좌표 저장 테이블, 업체 정보 API.

### 2.3 여행정보
*   **Frontend UI:** 펜션/숙박 캘린더 예약 현황 뷰, 당일 체크인/체크아웃 날짜 선택 폼.
*   **Backend API/DB:** 당일 중복 예약 방지를 위한 데이터베이스 락킹(Row-level Lock / Select for Update) 트랜잭션 API.

### 2.4 건강나라
*   **Frontend UI:** 운동시설(헬스, 필라테스 등) 회원권 가격 카드 리스트, 강사 소개 캐러셀, 상담 신청.
*   **Backend API/DB:** 강사 프로필 및 시설 이미지 스토리지 연동 DB.

### 2.5 병원정보
*   **Frontend UI:** 내과/치과 등 진료과목 필터, 요일별 영업시간 및 휴무일 표시 뱃지, 실시간 길찾기 링크.
*   **Backend API/DB:** 공공데이터 포털 병원 위치 API 연계 혹은 정적 데이터 적재 테이블.

### 2.6 부동산 (아파트)
*   **Frontend UI:** 아파트/전월세 면적 및 가격대 슬라이더 필터, 매물 상세 사진 슬라이드.
*   **Backend API/DB:** 매물 등록/수정/삭제 API, 평당 단가 자동 계산 트리거.

### 2.7 자동차
*   **Frontend UI:** 국산/수입/연식/주행거리 다중 필터링 검색창, 중고차 차량 점검기록부 PDF 뷰어.
*   **Backend API/DB:** 차량 옵션 플래그(열선, 내비 등) 비트마스킹 DB 설계.

### 2.8 알뜰생활 (중고거래)
*   **Frontend UI:** 당근마켓식 무료나눔/벼룩시장 피드, 채팅하기 단축 버튼, 거래 희망 장소 마크업.
*   **Backend API/DB:** 법정구역(동/구) 기준 인근 매물 검색 쿼리, 중고 매물 상세 DB.

### 2.9 상업산업 (B2B 디렉토리)
*   **Frontend UI:** 도매/제조업체 검색 디렉토리, 견적 다중 문의 폼(RFQ).
*   **Backend API/DB:** 다중 업체 동시 견적 발송 및 매칭 수신 알림 엔진.

### 2.10 구인정보
*   **Frontend UI:** 직무/근무지/급여 형태별 채용 공고 리스트, 간편 입사지원 버튼.
*   **Backend API/DB:** 채용공고 마감일 자동 계산 스케줄러.

### 2.11 인재정보
*   **Frontend UI:** 구직자 자기소개 및 보유 기술 스택 칩셋 필터링 리스트.
*   **Backend API/DB:** 이력서 PDF 파일 업로드 및 스토리지 링킹 DB.

### 2.12 알바정보
*   **Frontend UI:** 지도로 보는 인근 알바(GPS 기반), 단기/주말/야간 신속 필터 칩셋.
*   **Backend API/DB:** 유저의 위경도 반경 X km 내 알바 공고 검색 Spatial Query (MySQL Spatial Extensions / PostGIS 활용).

## 💰 4. 비용 및 작업 소요 기간 산정 공식 + 예시

내일 팀원 회의에서 즉석에서 숫자를 대입해 견적을 튕겨낼 수 있는 표준 프레임워크입니다.

### 4.1 소요 기간 및 비용 산정 공식

$$\text{작업 총 소요 일수 (MD)} = \text{기획/디자인 MD} + \text{프론트엔드 MD} + \text{백엔드 MD} + \text{QA/배포 MD}$$

$$\text{최종 제안 견적 금액} = \left[ (\text{나의 MD} \times \text{나의 일당}) + (\text{팀원 MD} \times \text{팀원 일당}) \right] \times (1 + \text{리스크 프리미엄 } 25\%)$$

*   *리스크 프리미엄(25%):* 기획이 중간에 바뀌거나 클라이언트의 자잘한 재작업 오더로 인한 예비비 버퍼.

---

### 4.2 내일 회의용 가상 시뮬레이션 예시
**가정:** 나의 일당 40만 원, 팀원 1의 일당 30만 원으로 조율 시.
*(※ Node.js 기반 백엔드 API 직접 구현 방안 채택으로 백엔드 공수 MD가 약 35% 상향 조정된 현실적인 가상 예시입니다.)*

| 개발 파트 | 상세 태스크 내용 | 나 (아키텍트/BE) | 팀원 1 (FE/UI) | 합산 예시 공수 |
| :--- | :--- | :---: | :---: | :---: |
| **1. 기획/디자인 조율** | 템플릿 커스텀 설계 및 와이어프레임 확정 | 2 MD | 3 MD | **5 MD** |
| **2. 프론트엔드 화면** | 핵심 카테고리(3개) 리스트, 상세, 280px 방어 UI | 3 MD | 9 MD | **12 MD** |
| **3. 백엔드 API 구축** | Node.js API 서버 구축, JWT 인증, 소켓 연동 | **12 MD** (3 MD 증가) | 3 MD | **15 MD** |
| **4. QA 및 스토어 배포** | AWS(EC2/RDS) 서버 세팅, Capacitor 앱 패키징 | 4 MD | 4 MD | **8 MD** |
| **공수 총계** | **2인 최종 MD 배분** | **21 MD** | **19 MD** | **40 MD** |

*   **가상 인건비 계산:** $(21 \text{ MD} \times 400,000\text{원}) + (19 \text{ MD} \times 300,000\text{원}) = 14,100,000\text{원}$
*   **리스크 버퍼 (25%):** $3,525,000\text{원}$
*   **최종 예시 견적가:** **17,625,000 원 (부가세 별도)**
*   **가상 소요 기간:** 2인이 병렬 개발하므로 **실제 제작 기간은 실근무 약 4.5주(영업일 21일)** 소요.

## 💸 5. 클라이언트 직접 지출 및 행정 조항 (R&R 선 긋기)

개발 공수 비용 외에 발생하는 고정비는 **클라이언트 법인 카드 직접 결제**를 원칙으로 하여, 개발자가 비용을 대납해 마진이 깎이는 리스크를 예방합니다.

### 5.1 인프라 및 솔루션 실비 (매달 변동 청구)
*   **서버/DB 인프라 (AWS):** AWS EC2(서버), RDS(데이터베이스), S3/CloudFront(이미지 CDN) 트래픽 비용.
*   **본인인증 API:** NICE/다날 본인인증 문자 인증 발생 시 **건당 약 30~40원** 청구.
*   **알림톡/SMS API:** 가입 및 매칭 완료 안내 문자 발송 시 **알림톡 건당 6~8원**, **문자 건당 15~45원** 청구.

### 5.2 최초 가입 및 등록 비용 (일회성)
*   **스토어 계정비:** Apple 개발자 계정 (연 $99), Google Play Console 계정 (최초 1회 $25).
*   **결제 시스템(PG):** 토스페이먼츠 등 가입비 (약 20~30만 원). 심사 기간이 최소 2주 이상 걸리므로 론칭 마일스톤에 사전 반영 필수.

### 5.3 법적/행정적 허가 조항 (클라이언트 법인 주체)
*   **통신판매업 신고:** 결제 기능을 위한 기본 신고.
*   **위치기반서비스사업자(LBS) 신고:** 알바정보 등 GPS 기반 지도를 매칭할 때 한국인터넷진흥원(KISA) 사전 신고 필수.
*   **직업정보제공사업 신고:** 구인/구직, 알바 정보를 웹에 게재하기 위해 고용노동부 사전 신고 필요.
*   *주의:* 위 법적 절차는 개발팀의 R&R이 아니며, 클라이언트 법인 명의로 직접 신고 및 획득해야 함을 계약서 비고란에 반드시 명시.
