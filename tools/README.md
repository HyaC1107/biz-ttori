# tools/ — T2 자동호출 래퍼 레지스트리

이 디렉토리는 **AI 호출 3단계 정책(`CLAUDE.md`)** 의 **T2(자동/툴)** 호출만 담는다.
T2의 조건: ① 출력이 짧고 정형화된 단답, ② **출력 캡 강제**, ③ 재질문 1회 한정.

> ⚠️ 대용량 코드 분석·리서치·문서 검증은 **T1(PM이 직접 `agy` 실행)** 영역이다. 이 디렉토리의 래퍼로 우회하지 말 것.

## 등록된 래퍼 (AI 호출 — T2)

| 스크립트 | 용도 | 출력 캡 |
|:---|:---|:---|
| `agy-ask.sh` | 젬또리(agy)에 짧은 단답형 질의 (DB 스키마/함수 시그니처/존재 확인 등) | 40줄 / 2000자, 초과 시 잘림 + T1 전환 경고 |

## 로컬 유틸리티 (모델 호출 없음 — 캡 불필요)

| 스크립트 | 용도 | 비고 |
|:---|:---|:---|
| `gbrain-doctor.sh` | 지브레인 `[[wikilink]]` 무결성 점검 (깨진 링크 = 환각 소스) | 결정론적 grep 검사. 코드블록/인라인코드/`{}`자리표시자 제외. 종료코드 1=깨짐 |
| `slack-post.sh` | Slack 단방향 알림 (Phase 1, Incoming Webhook). Step7 보고용 | 보내기 전용(캡 불필요). `keys/.env`의 `SLACK_WEBHOOK_URL` 사용. 인자 또는 stdin |

## 새 T2 래퍼 추가 규칙
1. 출력 캡(줄 수 + 문자 수)을 **반드시** 강제할 것. 캡 없는 자동호출은 정책 위반.
2. 단답 가드레일 프롬프트로 모델이 장황하게 답하지 못하게 묶을 것.
3. 캡 초과 시 "T1으로 전환" 신호를 stderr로 남길 것.
4. 추가 후 이 표에 한 줄 등록할 것.
