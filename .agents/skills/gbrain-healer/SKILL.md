# 🧠 gbrain-healer 스킬 실행 가이드 (젬또리 전용)

이 스킬은 비즈또리 워크스페이스 내에 깨진 위키링크(`[[링크]]`)를 탐색하여 지식의 부패를 방지하고 자동 교정하는 역할을 담당합니다.

## 🚦 실행 절차

젬또리는 이 스킬을 사용해 아래 단계를 거쳐 작업을 수행합니다.

### Step 1: 자동 힐러 스크립트 실행
* **명령어:** `./.agents/skills/gbrain-healer/scripts/heal.js`
* **역할:** 단순 오타(Levenshtein 거리 4 이하)로 인해 깨진 위키링크를 현존하는 파일명 리스트와 대조하여 자동으로 찾고 치환합니다.
* **판단:**
  * 종료 코드가 `0`이면 모든 깨진 링크가 깔끔히 치환된 것이므로 작업을 즉시 종료합니다.
  * 종료 코드가 `1`이면 자동 치환이 불가능한 '미해결 링크'가 남아있음을 뜻하므로 **Step 2**로 진입합니다.

### Step 2: 미해결 링크 문맥 분석 및 LLM 추론 교정
자동 스크립트가 찾아내지 못한 링크들은 단순 오타가 아닌 개념명 불일치나 누락입니다. 젬또리는 아래와 같이 지능적으로 개입하여 교정합니다.

1. **파일 조회:** 미해결 링크 리포트에 표시된 파일들을 `view_file` 도구로 열어 해당 `[[깨진링크]]`가 포함된 줄과 전후 문맥(Context)을 조회합니다.
2. **현존 노트 매핑 추론:** 전체 마크다운 파일들의 이름 및 주제를 보고, 깨진 링크의 명칭이 의미하는 바가 현존하는 다른 노트(예: `stack.md` 또는 특정 spec 파일 등)에 기술된 내용인지 매핑 추론합니다.
   * *예: `[[Zustand_Guide]]`가 깨졌는데 실제 파일 중 `Zustand.md`가 없는 경우 ➡️ 해당 기술이 [stack.md](file:///Users/linkcampus02/biz-ttori/memory/stack.md)의 Zustand 섹션에 있다면 `[[stack#Zustand|Zustand 가이드]]` 형태로 정밀 치환*
3. **링크 제거 및 텍스트 치환:** 만약 매핑할 대상 노트가 전혀 존재하지 않는 독자적인 정보라면, 거짓된 위키 링크 대신 일반 텍스트로 변경하거나 링크를 과감히 삭제합니다.
   * *예: `[[존재하지않는기획]]` ➡️ `존재하지 않는 기획` (링크 대괄호 `[[ ]]` 제거)*

### Step 3: 무결성 최종 검증
* **명령어:** `./tools/gbrain-doctor.sh`
* **목표:** 최종 무결성 점검기를 재실행하여 종료 코드 `0` (깨진 링크 0개)이 반환되는 것을 확인하고 작업을 마무리합니다.
