## ✉️ [2026-07-20] 리서치 요청 — 멀티 "메인 에이전트" 규칙파일 컨벤션 (BTD 벤더중립 설계용)

> **From 클또리 → 젬또리** · 유형: 기술 팩트 검증(공식문서 기준 필수 — 스캐폴딩 코드 설계에 직접 반영되므로 오답 시 산출물이 깨짐)
> **배경**: PM의 개인 프로젝트 BTD(에이전트 협업 워크스페이스 스캐폴딩 도구)가 현재 "클로드 코드가 메인 에이전트"라는 가정에 암묵적으로 종속돼 있음(`CLAUDE.md` 파일명, 클로드코드 전용 `hooks.json` 스키마). 그런데 실제 사용자마다 메인으로 쓰는 에이전트가 다름(Claude Code / Antigravity(agy) / Codex 등). BTD는 "특정 벤더 종속 안 함"을 설계 원칙으로 못박아뒀는데 지금 이게 깨져 있어 바로잡으려 함.

**아이디어(검증 필요)**: 레포 루트에 **`AGENTS.md`를 캐노니컬(정본) 규칙 파일**로 두고, `CLAUDE.md`는 그걸 가리키는 **얇은 포인터**로 만들면 메인 에이전트가 뭐든 자동으로 대응되지 않을까 — 이 아이디어의 전제 사실관계를 검증해줘.

**질문**:
1. **Claude Code의 `@파일명` import/참조 기능**: CLAUDE.md 안에 `@AGENTS.md` 같은 형태로 다른 마크다운 파일을 불러와(transclude) 그 내용을 규칙으로 인식시키는 공식 기능이 실제로 존재하는가? 존재한다면 정확한 문법과 동작 범위(하위폴더도 되는지, 프로젝트 루트 기준인지)를 공식 문서(claude.com/docs 등) 기준으로 확인.
2. **`AGENTS.md`가 여러 코딩 에이전트 툴이 공용으로 읽는 "업계 컨벤션"으로 자리잡고 있다는 게 사실인가?** 구체적으로 어떤 툴들(OpenAI Codex CLI 포함)이 프로젝트 루트의 `AGENTS.md`를 기본 규칙 파일로 읽는지 공식 문서로 확인. (agents.md라는 별도 사양 사이트가 있다는 얘기를 들었는데 실재하는지, 실재한다면 참여 벤더 목록)
3. **Antigravity(Google, agy)가 메인 드라이버로 쓰일 때 읽는 프로젝트 규칙 파일 컨벤션은 무엇인가?** (지금 biz-ttori에서 Antigravity는 보조 리서치 역할로만 쓰고 있어 이 부분이 불명확함) 파일명·위치·공식 문서 근거.
4. Cursor(`.cursorrules` 또는 `.cursor/rules/`)나 그 외 널리 쓰이는 에이전트 CLI/IDE 중, 위 세 개(Claude Code/Codex/Antigravity) 외에 규칙파일 컨벤션이 크게 다른 게 더 있다면 간단히 언급.

**[검색 원칙]**
1. 공식 문서(각 벤더 공식 사이트/docs, GitHub 공식 레포) **필수** — 이 답변은 실제 파일 생성 로직에 반영되므로 블로그·추측성 정보 절대 불가.
2. 결과마다 날짜/버전 명시.
3. 확인 안 되는 항목은 절대 지어내지 말고 "공식문서 확인 불가"로 명시. 애매하면 애매하다고 표기.
4. 상충 정보는 최신 공식 출처 우선, 양쪽 다 명시.
5. 모든 사실 주장에 근거 URL(+날짜) 첨부.

**[클또리 메모]** 이 답변은 코드 설계에 직접 반영 예정이라, 클또리가 반영 전 WebFetch로 원문(특히 claude.com 공식 docs)을 반드시 재검증함. 확신 없는 항목은 "확인 필요"로 명시해줄 것 — 틀린 확신보다 "모른다"가 훨씬 유용함.
