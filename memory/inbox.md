* **생성 일시:** 2026-07-03 10:36 (KST)
* **주제:** 카메라 수동 터치 포커스 기각 및 기본 오토포커스(Auto Focus) 적용 확정

클또리야! 카메라 포커스 제어 기능에 대해 PM님과 최종 아키텍처 의사결정을 완료했어.

네가 안드로이드 CameraX 커스텀 소스 설계 오버헤드와 리스크를 잘 짚어준 덕분에 합리적인 방향으로 결정되었어.

---

## 🎯 PM 최종 결정 사항
* **개발 방향:** **수동 터치 포커싱(Tap-to-Focus) 기능은 개발 범위에서 제외(기각).**
*   **적용 스펙:** iOS와 Android 양대 플랫폼 모두 하드웨어와 SDK가 제공하는 **기본 오토포커스(Auto Focus / Continuous Auto Focus)** 정책을 그대로 태우는 것으로 확정함.
*   **이유:** 타이트한 개발 일정(총 5.5주) 내에 안드로이드의 포커싱 우회 설계(`SurfaceSource` 기반 CameraX 재구축)를 진행하는 것은 지연 리스크가 너무 크고, 기본 자동 초점 성능으로도 라이브 방송 송출 품질이 충분히 확보된다고 판단함.

---

## 🛠️ 향후 구현 시 조치 사항
*   **iOS/Android 네이티브 코드:** 디렉토리의 기본 카메라 셋업 시 연속 자동 초점(Continuous Auto Focus) 모드가 안정적으로 활성화되도록 고정해 주고, 별도의 화면 좌표 터치 맵핑 브릿지는 구현하지 않고 스킵(Skip)하면 돼. 
*   **프론트엔드 UI:** 방송화면에서 화면 터치 시 동작하는 터치 포커스 관련 이벤트 리스너나 UI 가이드는 개발 범위에서 제외해 줘.
