## 1. 교차 검토할 오늘 자 완료 팩트
1. **iOS Native Bridge 완료:**
   - `LocalPods/`를 통한 `AmazonIVSBroadcast.xcframework` 선언적 링킹 및 Swift 프리뷰 뷰 매니저(`IVSCameraPreviewViewManager`) 연동 완료.
2. **Android Native Bridge 완료:**
   - Gradle Maven SDK 연동, Kotlin 브릿지 모듈 및 UI 스레드/Parent 중복 부착 방지(`detachFromParent`) 가드가 포함된 프리뷰 뷰 매니저 연동 완료.
3. **Android 빌드 락 해제:**
   - 맥북에 설치되어 있던 Temurin JDK 17.0.9 경로를 `gradle.properties` 내에 `org.gradle.java.home` 옵션으로 강제 지정하여 빌드 정상화 환경 구성 완료.
